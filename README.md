## Overview

Boss Cursor is a small Terraria utility mod that displays real-time cursor world coordinates and the distance from the player to the currently targeted boss. It aids speedrunners measuring precise spawn positions and players tracking boss movement patterns, displaying the information in a compact HUD overlay that does not obscure gameplay.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Boss Cursor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Cursor Coordinates** | Displays cursor world X and Y coordinates in real time |
| **Boss Distance** | Shows current distance from player to active boss entity |
| **HUD Overlay** | Non-intrusive small overlay that does not block gameplay elements |
| **Speedrun Utility** | Useful for precise boss spawn positioning in competitive runs |
